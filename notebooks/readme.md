# Notebooks

이 폴더는 데이터 탐색(EDA), 실험, 모델 학습 및 결과 분석을 위한 Jupyter Notebook을 관리합니다.

## 목적
1. 데이터 탐색 및 시각화
2. 모델 학습 및 성능 비교
3. 실험 결과 기록
4. 아이디어 및 프로토타이핑

## 권장 사항
1. 실험마다 Markdown 셀을 활용하여 목적, 변경 사항, 결과를 기록합니다.
2. 실험이 완료되면 결과를 README 또는 프로젝트 문서에 정리합니다.
3. 동일한 목적의 Notebook을 여러 개 생성하기보다 기존 Notebook을 관리하며 버전을 정리합니다.
4. 공통으로 사용하는 함수나 클래스는 Notebook이 아닌 프로젝트 코드 디렉터리(src/ 등)에 작성하여 재사용합니다.
