# Source Code

이 폴더는 프로젝트에서 사용하는 **핵심 소스 코드**를 관리합니다.

Notebook에서 검증이 완료된 코드나 재사용이 필요한 기능은 `src/`로 이동하여 관리합니다.

## 목적

* 데이터 처리 로직 관리
* 모델 정의 및 학습 코드 관리
* 추론(Inference) 코드 관리
* 공통 함수 및 유틸리티 관리
* 프로젝트 코드 재사용성 향상

## 작성 규칙

* 재사용 가능한 코드는 Notebook이 아닌 `src/`에 작성합니다.
* 하나의 파일은 하나의 역할만 담당하도록 구성합니다.
* 공통으로 사용하는 함수는 중복 작성하지 않고 모듈화합니다.
* 하드코딩된 값은 최소화하고 Config를 통해 관리합니다.
* 함수와 클래스는 역할이 명확하도록 작성합니다.

## 예시 구조

```text
src/
├── datasets/         # Dataset 및 DataLoader
├── models/           # 모델 정의
├── train/            # 학습 로직
├── inference/        # 추론 로직
├── evaluation/       # 평가 및 Metric
├── augmentation/     # 데이터 증강
├── utils/            # 공통 유틸리티
└── visualization/    # 시각화
```

> 실제 프로젝트 진행에 따라 디렉터리 구조는 변경될 수 있습니다.

## 역할

Notebook에서는 실험과 검증을 수행하고,

`src/`에서는 프로젝트에서 실제 사용하는 코드를 관리합니다.

즉,

* **Notebook:** 실험 및 분석
* **src:** 재사용 가능한 프로젝트 코드

의 역할을 구분하여 유지합니다.
